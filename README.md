## ✨ Features

- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎨 Clean and modern user interface
- ⚡ Built with React and Vite
- 🧩 Component-based architecture
- 🎯 Smooth navigation between sections
- 💼 Dedicated projects showcase
- 🛠️ Skills and technology section
- 🎓 Education timeline
- 📬 Contact section with social links
- 🔗 Direct GitHub and LinkedIn integration
- ☁️ Deployed using Vercel

---

## 📑 Sections

The portfolio includes:

- 🏠 **Home** — Introduction and developer profile
- 👨‍💻 **About Me** — Background and career interests
- 🎓 **Education** — Academic journey
- 🛠️ **Skills** — Technical skills and technologies
- 🚀 **Projects** — Selected development projects
- 📜 **Certifications** — Learning and certifications
- 📬 **Contact** — Ways to connect with me
